# 不兑元技能 · budui-meta-skill

把重复工作整理成你自己的 Skill。先确认需求，再生成；新技能统一以 budui- 开头，默认作者为不兑。

你可以直接这样说：使用 budui-meta-skill，帮我把这个工作流程做成技能，先和我确认需求。

个人小工具采用轻量流程；复杂或发布类任务保留研究、验证和安全检查。
当前为本地安装的个人分支，未发布，不提供虚构的 npx skills add 地址。

GitHub 偏好：https://github.com/chuopen/ 。账号以运行时登录为准，可见性需明确。

来源：https://github.com/joeseesun/qiaomu-meta-skill ，基于 2.8.1 定制。原 LICENSE 保留。
历史 reports 为上游证据，不代表本分支已完成相同验证。

验证：scripts/validate_skill.py 用于完整包规范检查；个人 Scaffold 不强制套用完整包规范。
Troubleshooting：如仍出现旧名，刷新技能列表或新开对话。未来安装上游版本不会自动合并本地定制。
