# budui-voc-weekly · VOC 新车周报生成器

导入人工校验后的 VOC 明细 Excel，说一句「出上周的周报」或「出 9.6 到 9.12 的周报」，即可得到一份周报 HTML 简报、一张可直接发群的 PNG 长图和一份带溯源 Sheet 的导出 Excel。数据文件里有上一周期数据时自动算环比。统计口径由脚本固定执行，每次产出数字一致、可核对。

姊妹技能：`budui-voc-daily`（单日日报）。两者共用同一套字段识别与去重口径，周报的逐日数字与日报同日期完全一致，可互相核对。

## 安装

- 上传到 WorkBuddy 等 Agent 平台：直接上传本技能目录（含 `SKILL.md` 与 `scripts/`）。
- 本地使用：把目录复制到 `~/.zcode/skills/`（或其他技能目录），或直接在目录内运行脚本。

依赖：Python 3.8+ 与 `openpyxl`（`pip install openpyxl`）；PNG 长图另需本机 Edge/Chrome 与 `Pillow`（可选，缺失时自动降级）。

## 使用

对装了本技能的 Agent 说：

- 「出上周的 N7 周报」
- 「9 月 6 号到 12 号出新 N7 的周报」
- 「N6 和 NX8 各出一份，车友群要点也放进去」

Agent 会自动识别工作表与字段 → 确认新车车系与周期 → 生成：

| 产物 | 内容 |
|---|---|
| `VOC新车周报_<车系>_<起>-<止>.html` | 指标卡（含环比）、周情感结构、逐日趋势（堆叠柱＋负面占比折线）、周观点 TOP5、热门话题 TOP3、逐日明细、数据来源与识别口径；自包含可离线打开 |
| `VOC新车周报_<车系>_<起>-<止>.png` | 周报整页长图（自动裁掉底部空白），直接发微信群用 |
| `VOC新车周报_<车系>_<起>-<止>.xlsx` | 总览、观点、热门话题、负面VOC清单、VOC明细 五个 Sheet，溯源首列为真实日期单元格，可直接排序筛选透视 |

## 数据要求

- 人工校验后的 VOC 明细 Excel，含：日期列（建单时间/数据日期/日期等）、情感列、标签类型列、观点标签列、四级标签列；有车系列与 OneID/VIN/服务单号时去重更完整。
- 字段名不完全一致没关系，脚本按候选名模糊识别；识别失败会明确列出缺失项，可手动指定列。
- 周报支持任意起止区间（不限于 7 天、不要求自然周）；当前口径只分析单一指定车系（"新车"），不做车系间对比。

## 核心口径（摘要）

- 同一日期内三轮串行去重：①OneID＋观点＋四级标签；②VIN（规范化）＋观点＋四级标签；③服务单号＋观点＋四级标签；占位符无效，按日去重、不跨日合并。周报＝逐日去重后按周期聚合。
- 全部指标为报告周期口径；用户量为周期内 OneID 去重（跨天 union），不等于逐日相加。
- 环比＝紧邻上一等长周期（不按自然周对齐）：总量/用户量为百分比变化，负面占比为百分点（pp）差；上一周期无数据时不计算，不编造对比。
- 情感按"正/中/负"关键词归类，无法归类的单列为未识别，不并入三类。
- 完整口径见 `references/data-spec.md`，产出规范见 `references/report-spec.md`。

## 边界

不用于单日日报（用 `budui-voc-daily`）、月报/多周聚合、多车系横向对比、模型准确率监控，以及没有人工校验标签的原始数据。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示缺少 openpyxl | 执行 `pip install openpyxl` 后重试 |
| 报「必需列识别失败」 | 按报错里的表头清单，用 `--col 日期=列名,情感=列名,...` 手动指定 |
| 报「车系 XXX 无记录」 | 车系名要与 inspect 输出的车系清单完全一致（区分大小写与全半角） |
| 报「周期内无去重后数据」 | 周期不在数据范围内，按报错里列出的该车系可用日期改周期 |
| 周报里没有环比 | 数据文件里没有上一周期数据，属正常降级；需要环比就把上一周期的数据并入文件 |
| 生成的周报车系不对 | 检查是否把其他车系当成了新车；inspect 的车系清单是唯一可选来源 |

## 背景与来源

为「新车周报」场景定制，从 `budui-voc-daily` 派生：保留其工作表选择、字段识别、情感归类与三轮按日去重引擎（已用真实数据验证周报逐日数字与日报一致），把"当日口径"全面改为"周期口径"，新增口语周期换算、紧邻等长周期环比、逐日明细合计行与 PNG 底部精确裁边。
