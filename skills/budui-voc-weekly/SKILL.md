# VOC 新车周报

把一份人工校验后的 VOC 明细 Excel 变成一份周期新车周报（HTML 简报 + PNG 长图 + 导出 Excel）。统计口径全部由 `scripts/generate_weekly.py` 固定执行，不要手写统计代码或口头估算数字。

## 何时使用 / 不使用

使用：用户导入 VOC 明细 Excel 并要求生成某个周期（一周或任意起止区间）的周报（"出上周的周报""要 9.6 到 9.12 的周报"）。
不使用：**某一天**的日报（用 `budui-voc-daily`）、月报/多周聚合、车系横向对比分析、模型准确率监控、没有人工校验标签的原始数据——这些直接答复或另建技能。

## 工作流

### 1. 环境检查

```bash
python -c "import openpyxl" 2>/dev/null || pip install openpyxl
```

### 2. 探测结构（必做）

```bash
python scripts/generate_weekly.py inspect <excel路径>
```

读取 JSON 输出：选中的工作表、9 个字段映射、**车系清单及条数**、日期范围、缺失字段。
- `missing_required` 非空 → 把缺失字段和表头清单告诉用户，让用户指定列名，用 `--col 日期=列名,情感=列名,...` 重试。
- 用户点名了某个工作表 → 加 `--sheet`。

### 3. 确认新车车系（必做，不可跳过）

车系是**自动识别**的，但"哪个车系算新车"必须由用户决定。向用户展示 inspect 的车系清单（如 NX8 1572 条、N7 1280 条…），问一句："哪个车系是本期的新车？"

- 用户已在对话里说明（"出 N7 的周报"）→ 不再重复问。
- 用户要多个车系 → 每个车系各执行一次 generate，产出多份周报。

### 4. 确认报告周期

把用户的口语周期换算成 `--start` / `--end`（`YYYY-MM-DD`）：

- 明说了起止（"9 月 6 号到 12 号"）→ 直接用。
- 说"上周"这类相对周期 → 取紧邻的上一自然周（周一至周日），换算后**复述一句**（"上周即 10 月 5 日（周一）至 10 月 11 日（周日）"），用户没异议即执行。
- 只说了一头（"截至 9 月 12 号的一周"）→ 只传对应参数，脚本自动取 7 天窗口。
- 完全没说周期 → 不问，用该车系数据的全部日期，并在汇报时说明实际覆盖范围。

周期内无数据时脚本会报错并列出该车系可用日期范围——如实告诉用户，不要自行改周期。

### 5. 生成周报

```bash
python scripts/generate_weekly.py generate <excel路径> --series N7 \
  [--start 2026-09-06 --end 2026-09-12] [--outdir 输出目录] \
  [--title "VOC 新车周报"] [--group-extra "车友群要点1|要点2"]
```

- `--group-extra`：用户提供了车友群截图/文本时，提取要点后用 `|` 分隔传入；没有就省略。
- 输出目录：用户没指定时用 `--outdir <excel同目录>/周报输出`。
- 默认同时输出 PNG 长图（脚本自动调用本机 Edge/Chrome 无头截图并裁掉底部空白）；环境无浏览器或无 PIL 时 JSON 里 `png` 为 `null` 并附 `png_note`，如实说明即可，不要尝试用其他方式截图。

### 6. 汇报（必须做）

生成成功后，读 stdout JSON，用中文向用户汇报并给出文件路径：

1. 一句话结论：本期 VOC 总量、用户量、负面占比；有环比时带上变化（"较上周 +12.5%，负面占比 +2.1pp"），并注明是与哪个周期比
2. 负面 TOP 话题（`top_topics` 里产品侧/服务侧第一条）
3. 三个产物文件路径（HTML 周报 + PNG 长图 + 导出 Excel）；PNG 用于直接发群
4. 数据口径提示：统计的车系、报告周期、去重口径已写入周报"数据来源与识别口径"节；没说周期时说明实际覆盖范围

## 边界与注意

- 数字一律以脚本 stdout JSON 为准；不要凭记忆复述或心算改数。
- 车系值必须原样取自 inspect 的 `series_values`（如 `N7`，不是"新N7"），脚本按字符串精确匹配。
- 全部指标为报告周期口径；环比的上一周期是紧邻等长区间（不按自然周对齐），上一周期无数据时不算环比，不要编造对比数字。
- 用户量是周期内 OneID 去重（跨天 union），不等于逐日用户量相加；去重是按日去重、不跨日合并——周报逐日数字与日报同日期一致是这条口径保证的。
- 导出 Excel 的百分比以小数输出（0.3898），在 Excel 中套用百分比格式即显示 38.98%。
- 周报 HTML 自包含（内嵌 SVG，无外网依赖），可直接发群或浏览器打开。
- 更细的字段识别规则、周期与环比口径见 [references/data-spec.md]；周报内容结构见 [references/report-spec.md]。
