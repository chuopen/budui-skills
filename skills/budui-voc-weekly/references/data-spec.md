# 数据识别与统计口径

脚本 `scripts/generate_weekly.py` 按本文件执行。改口径先改这里和脚本，再验证。

数据识别、情感归类与去重口径与 `budui-voc-daily` 完全一致（同一批人工校验数据在两个技能里的读法相同，周报逐日数字应与日报可互相核对）；差异在周期口径与环比。

## 工作表选择

1. 对每个工作表的前 3 行读表头，按字段候选命中打分：必需字段（日期/情感/标签类型/观点/四级标签）各 +2，车系 +1，OneID/VIN/服务单号各 +0.5。
2. 只在可见表中选；可见表无候选时回退隐藏表并在输出中标注。
3. 同分取数据行多者。列数少于 5 的表不参评。

理由：真实文件里"数据行最多"的工作表可能是隐藏的模型校验窄表（2 万行、无车系列），按行数选会选错；按结构特征选不会。

## 字段识别

列名先 normalize（去空白、全角括号/字母数字转半角），再按候选顺序匹配：先精确相等，后包含。每个字段取第一个命中列，不重复占用。

| 字段 | 候选（按优先级） |
|---|---|
| 日期 | 建单时间 > 数据日期 > 日期 > 校验日期 |
| 车系 | 车系（人工修正）> 车系（排除含"基准/原始/码/类型/版本"的列） |
| 情感 | 情感（人工修正）> 正负面（修正）> 正负面 > 情感 |
| 标签类型 | 标签类型（人工修正）> 标签类别（修正）> 标签类型 > 标签类别 |
| 观点标签 | 观点标签（人工修正）> 观点（补充）> 观点标签 > 观点 |
| 四级标签 | 四级标签（人工修正）> 四级分类（修正）> 四级标签 > 四级分类 |
| 去重键 | OneID / VIN码 / 服务单号（存在才启用对应去重轮） |

必需字段（日期、情感、标签类型、观点、四级标签）任一缺失 → 阻断并列出表头，等用户用 `--col` 指定。车系列缺失同样阻断 generate（新车周报必须能筛车系）。

## 日期解析

取日部分统计。兼容：日期型单元格、`YYYY-MM-DD`/`YYYY/M/D`/`YYYY年M月D日`/`YYYYMMDD` 等文本、Excel 序列号（50000 以内数字或文本形态，自 1899-12-30 起算）、全角数字。解析失败的行不计入统计，数量在输出中标注（`bad_dates`）。

## 情感归类

原值含"正"→正面；含"负"→负面；含"中"→中性；英文 positive/negative/neutral 同理。其余（空白、其他字样）计为"未识别"，单列展示与导出，不并入三类。

## 去重口径（页面与导出同口径）

同一日期内（日期取日部分）三轮**串行**去重，每轮保留组内第一条：

1. OneID ＋ 观点标签 ＋ 四级标签
2. VIN码（去空格、转小写）＋ 观点标签 ＋ 四级标签
3. 服务单号 ＋ 观点标签 ＋ 四级标签

OneID/VIN/服务单号为空或占位符（`-`、`无`、`NA`、`null`、`/`、`未知` 等）时该轮不去重、原样保留。**按日去重，不做跨日合并**——周报是"逐日去重后按周期聚合"，不是"周期内跨日去重"，同一用户连续两天反馈同一条问题计 2 条。周报逐日数字与日报同日期数字完全一致，正是这条口径保证的。

## 周期解析

`--start` / `--end` 都给 → 按区间；只给一头 → 取 7 天窗口（start 锚定向前补，end 锚定向回补）；都不给 → 该车系数据的全部日期。`start` 晚于 `end` 报错。周期内无该车系去重数据时报错并列出该车系可用日期范围。

"上一周期"固定定义为紧邻的等长区间：`[start − N 天, start − 1 天]`，N 为周期天数。不按自然周对齐——数据里的周期未必是周一制。

## 统计口径（全部为报告周期口径）

- **总量**：周期内按日去重后记录数。**用户量**：周期内 OneID 去重（跨天 union，同一用户多天反馈只计一次，空值不计）——因此不等于逐日用户量相加，页面合计行与 Excel 均注明。**观点量**：与总量同口径。
- 情感结构：正/中/负及占比、未识别；负面占比 = 周期负面 ÷ 周期总量，分母含未识别，页面与 Excel 注明。
- 观点 TOP5：标签类型分产品侧/服务侧 × 三种情感，按周期累计计数。
- 热门话题 TOP3：人工修正四级标签，按周期累计声量，每项含周期内逐日趋势与峰/谷值；同分按标签名称排序。
- 侧别判定：标签类型含"产品"→产品侧，含"服务"→服务侧，其他归"其他"。

## 环比口径

与"上一周期"对比，上一周期内该车系无去重数据时不计算（stdout `prev`/`delta` 为 `null`，页面指标卡不显示环比）。

- 总量、用户量：百分比变化 `(本期 − 上期) ÷ 上期 × 100%`，保留 1 位小数。
- 负面占比：百分点差（pp），保留 1 位小数。
- 上期或本期用户量为 0 时用户量环比不计（`null`），其余照算。
- 环比是参考读数：两期数据量、覆盖渠道不同时不构成严格对比，汇报时如实带出口径即可。
