# 周报内容与产出规范（output contract）

## 产出文件

文件名前缀 `VOC新车周报_<车系>_<YYYYMMDD>-<YYYYMMDD>`，三个产物：

| 文件 | 内容 |
|---|---|
| `.html` | 单文件自包含（内嵌 CSS 与 SVG，无外网、无 JS 依赖），浏览器打开即读 |
| `.png` | 整页长图，直接发群用；脚本自动调用本机 Edge/Chrome 无头截图，找不到浏览器时跳过并在 stdout JSON 中说明（`png: null` + `png_note`），不阻断周报交付 |
| `.xlsx` | 导出 Excel，五个 Sheet |

视口高度首轮按 `est_height` 估算（固定区块 2702 ＋ 实际行数累加 ＋ 6% 余量，宁可高估）；截图成功后用 PIL 自底向上扫描背景色，把底部空白裁到页脚下 48px（PIL 缺失时跳过裁切，底部可能留白但不裁内容）。截图文件在浏览器退出后延迟 1-2 秒落盘，脚本轮询等待；首次失败自动重建 profile 重试一次。浏览器子进程不继承相对路径，输出目录在脚本内强制转绝对路径。

## 周报 HTML

文件名 `VOC新车周报_<车系>_<YYYYMMDD>-<YYYYMMDD>.html`。分区顺序固定：

1. 标题栏：周报标题 · 车系 · 报告周期（起止日期＋天数） · 车系筛选说明
2. 指标卡：周 VOC 总量、周用户量、周负面占比（周期口径）；有环比时各卡附小字（总量/用户量为百分比变化，负面占比为 pp，负面占比上升红/下降绿，其余灰）
3. 周情感结构：正/中/负三行，数量＋占比＋进度条；有未识别记录时加警示行
4. 每日 VOC 趋势：SVG 堆叠柱（正/中/负）＋负面占比折线（橙圆点＋百分比标注），横轴为周期内每个日历日（无数据日显示空柱），图例齐备；左轴计数、右轴负面占比，轴下限保证小数据量时刻度仍为有效整数
5. 周观点榜：产品侧、服务侧各一行三列（正/中/负 TOP5，周期累计），观点量用浅色轨道未填满横条
6. 热门话题 TOP3：产品侧、服务侧各一表，四级标签＋周期累计声量＋逐日迷你趋势（峰值红点）＋峰/谷日期与数值
7. 逐日明细表（日期、正、中、负、未识别、合计、用户量）＋ 合计行；合计行用户量为周期 OneID 去重数并注明"不等于逐日相加"
8. 车友群动态（仅当传入 `--group-extra`）
9. 数据来源与识别口径：文件名、工作表、报告周期、日期列、车系筛选、参与统计行数链路（车系命中 → 按日去重 → 周期内）、上一周期与环比数值（或"无数据未计算"）、去重口径全文；可折叠查看识别字段映射
10. 页脚：生成工具与生成日期

视觉：暖白底、白卡片、橙色主色（#e8730c）、情感色固定（正面绿 #2e9e5b / 中性灰 #8a94a6 / 负面红 #d64545）；环比色（负面占比上升红 #d64545 / 下降绿 #2e9e5b / 其余灰）；所有用户数据经 HTML 转义。

## 导出 Excel

文件名 `VOC新车周报_<车系>_<YYYYMMDD>-<YYYYMMDD>.xlsx`，五个 Sheet：

| Sheet | 内容 |
|---|---|
| 总览 | 信息块（文件名、工作表、报告周期、车系筛选、日期列、车系命中行数、按日去重数、周期内记录数、用户量、观点量、未识别、负面占比小数、上一周期及其记录数、环比数值或"无数据"说明、去重口径、识别字段映射）＋ 逐日表（含用户量列、合计行、用户量口径说明行） |
| 观点 | 侧别 × 情感 × 排名 × 观点标签 × 数量（周期累计） |
| 热门话题 | 侧别 × 排名 × 四级标签 × 周期累计声量 × 峰值日期/值 × 谷值日期/值 |
| 负面VOC清单 | 报告周期内该车系去重后情感为负面的全部记录，首列为日期列（真实日期单元格，格式 `yyyy-mm-dd hh:mm:ss`），其余列沿用源文件表头 |
| VOC明细 | 报告周期内该车系全部去重记录，首列日期前置，其余沿用源文件列 |

负面占比以小数输出（0.3898），Excel 中套百分比格式即显示 38.98%。

## stdout 摘要 JSON（给汇报用）

```
ok / html / png / png_note / excel
stats{start, end, days, series, total, users, sentiment{正面,中性,负面},
      unrecognized, negative_ratio,
      prev{total, users, negative_ratio} | null,
      delta{total_pct, users_pct, negative_pp} | null}
top_topics{产品侧: [[标签, 声量]…], 服务侧: […]}   // 各 TOP3，汇报话题用，不必解析 HTML
```

PNG 成功时 `png` 为路径，失败为 `null` 并附中文 `png_note`。

## 验证清单（每次改动脚本后必跑）

1. inspect 对真实文件能识别全部 9 个字段、车系清单、日期范围
2. generate 后：`stats.total` ＝ VOC明细数据行数；`sentiment.负面` ＝ 负面VOC清单行数；逐日合计行 ＝ 逐日相加；周报逐日数字与 `budui-voc-daily` 同日期日报一致
3. 有上一周期数据时：`delta` 手工复算通过（(本期−上期)/上期、pp 差）；无数据时 `prev`/`delta` 为 `null` 且页面不显示环比
4. HTML 打开无乱码、图表渲染、口径数字与 stdout 一致；周期内无数据日显示空柱
5. Excel 五个 Sheet 齐全，溯源 Sheet 首列日期可直接排序筛选
6. PNG 页脚完整可见、底部空白 ≤ 60px（裁切回归检查）
