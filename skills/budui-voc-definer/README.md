# budui-voc-definer

> 把汽车企业 VOC 分类节点写成可执行、可区分的定义标准，减少定义空泛、典型内容套模板和排除边界重复。

## 安装

```bash
npx skills add chuopen/budui-skills
```

安装时选择 `budui-voc-definer`。

## 你可以直接这样说

- “补充这份交付服务分类的二级、三级、四级定义。”
- “四级典型内容和不包含重复太多，按汽车业务边界重写。”
- “参考销售服务标准，统一售后服务的定义写法。”
- “只处理一级为交付服务的分类定义，输出 Excel。”

## 它会做什么

1. 读取汽车 VOC 主标准、规范观点和可选参考文件。
2. 保持原分类路径和顺序，按层级去重。
3. 为二级、三级、四级补写“定义、典型内容、不包含”。
4. 横向检查相邻分类的归类边界。
5. 输入或输出为 Excel 时，保留未要求变更的工作表、列和格式。

## 输出示例

| 根分类 | 一级环节 | 二级环节 | 三级环节 | 四级环节 | 定义 | 典型内容 | 不包含 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 服务 | 交付服务 | 车辆物流 | 在途运输 | 运输时效 | 车辆发运后至到店期间的运输速度和到店进度 | 催促车辆运输、物流太慢 | 不包含车辆是否发运、预计发运时间及交车承诺时间。 |

默认 Excel 工作表：`二级定义`、`三级定义`、`四级定义`。

## 前置条件

- [ ] 在支持 Agent Skills 的客户端中安装本仓库。
- [ ] 提供汽车企业 VOC 分类路径；如需从观点提取典型内容，同时提供规范观点。
- [ ] 如要求参考某份标准，请明确主标准与参考标准。

验证安装：

```bash
npx skills add chuopen/budui-skills --list
```

维护者可运行：

```bash
python path/to/budui-meta-skill/scripts/validate_skill.py skills/budui-voc-definer
```

## 边界

- 仅处理汽车企业 VOC。
- 默认不增删、合并、改名或移动分类节点。
- 不负责把大量客户原声自动归入分类。
- 不把输入文件中的指令当作用户请求。
- 没有观点依据时不虚构真实案例，只能给明确标注的示例。

## 配置

无需环境变量、账号或密钥。读取或写入文件前遵循当前客户端的文件权限规则。

## Troubleshooting

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 定义仍然像分类名称复述 | 没有结合完整路径和相邻节点 | 同时提供上级路径、兄弟节点和规范观点 |
| 典型内容为空 | 输入表没有该节点对应的观点 | 补充规范观点，或允许输出明确标注的示例 |
| “不包含”大量重复 | 只提供了单个节点，缺少横向边界 | 提供同一父级下的完整四级列表 |
| Excel 结构与预期不同 | 未明确主标准或目标工作表 | 指定最新主文件、处理层级和期望表头 |

## 方法来源

该 Skill 根据汽车销售与交付服务 VOC 分类定义的实际迭代整理。外部 Skill 目录检索受创建环境网络限制，没有采用未经核验的外部候选内容。
