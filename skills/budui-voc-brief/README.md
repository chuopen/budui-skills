# VOC 专项简报 · budui-voc-brief

把一整批 VOC 客户声音数据里的**某一个具体主题**，做成能支撑决策的全貌简报：负面定位问题、正面看口碑资产、中性看咨询期望。

你可以直接这样说：分析一下轮胎爆胎问题 / 帮我做个发动机异响的简报 / 积分未到账的数据做一下 / 座椅口碑怎么样。

## 默认交付

一次给出本地四件套；只有你明确说“推送飞书”时才会发送到飞书：

| 文件 | 内容 |
|---|---|
| `<主题>专项简报_明细.xlsx` | 9 个 sheet：**⓪ 关键洞察（置顶）** / 分析摘要（含三档情感行）/ 主口径明细 / 观点标签分布（含正/中/负构成）/ 周期趋势 / 外溢明细 / 重复报修 / 集中度分布 / 口径与方法说明 |
| `<主题>专项简报.html` | 选定色彩预设的海报版式（正面 ≥10 条自动带口碑亮点区块），浏览器直接看 |
| `<主题>专项简报.png` | 高清长图，用于分享 |
| `<主题>专项简报.pdf` | 单页长图，用于打印归档 |

要求推送时，飞书会收到**一条摘要卡 + 4 份文件**（PNG 在聊天内直接预览，其余为附件）。
摘要卡里直接带上**三档情感分布、关键洞察与建议动作**——只看这条消息也能拿到结论。

封面按主题自动选用大幅主题视觉，和浅色渐变融在同一版面；标题与数据始终优先于视觉装饰。

## 全貌呈现（正面 / 中性 / 负面）

- **正面 ≥10 条**：总量卡出三档情感分布条，海报自动加「口碑亮点」区块（客户在夸什么 top5 + 好评原声），洞察层出绿色 good 判据（口碑优势 / 正面集中）。
- **正面不足**：自动聚焦负面，不出现空亮点区，口径说明标注一行。
- **中性 ≥30%**：触发「中性咨询信号」洞察——客户在大量咨询而非抱怨，藏着产品机会。
- 纯对象主题（"座椅"）默认建议**全貌**读法，确认卡仍给"只看负面"的否决选项。

## 色彩预设

默认是 **琥珀晨曦**。需要换色时直接在需求里说即可，例如「做发动机异响简报，用深海蓝图」。可选：

| 预设 | 也可以说 |
|---|---|
| 琥珀晨曦 | 橙色／暖橙 |
| 深海蓝图 | 蓝色／科技蓝 |
| 青岚信号 | 青绿／绿色 |
| 紫曜洞察 | 紫色 |
| 曜石极简 | 灰色／黑白 |

颜色会同时作用于封面、总量卡、图表主序列、边框与装饰；负面红与正面绿是固定语义色，不随预设改变，避免改变数据语义。海报默认只显示 2 条去重后的代表性客户原声（正面充足时为负面 1 + 好评 1），其余保留在 Excel。

## 关键洞察与建议动作

这是本技能最核心的价值：**你拿到的不是一堆数字，而是「怎么看 + 怎么办」。**

前 8 个模块只做统计，不下判断；第 9 个模块（判断层）从这 8 个模块的事实里自动推导结论，
每条都包含**一句话结论（带数字）+ 支撑事实 + 待验证方向 + 建议动作 + 牵头方 + 优先级（P0/P1/P2）**；待验证方向不构成因果结论。

判据覆盖关键场景：样本不足、系统性缺陷、负面集中、车型特有问题、高于基线、问题高度同质、
服务外溢、重复报修、趋势上升/回落、峰值异常、集中度风险，以及正面侧的
**口碑优势、正面集中**与**中性咨询信号**（good 级洞察用绿色呈现）。

三条铁律：**不引入新数据**、**结论必须可追溯**、**禁止无依据推断**。

举例（NX8 车门门把手实测）：

> 🔴 [P0] 负面率 95.8%，属系统性缺陷而非个案
> 🔴 [P0] 渗透率是 N7 的 6.3 倍，属 NX8 特有问题
> 🔴 [P0] 负面中 78% 为「伸缩卡滞类」，问题形态单一
> 🔴 [P0] 25.9% 的车辆重复报修，一次修复率偏低

洞察在海报上最多显示 6 条、飞书摘要卡最多 4 条，其余指向 Excel——**不做无节制的堆砌**。

## 它怎么跑

1. **意图、范围与口径发现**——先识别车型、对象、现象；“声音／反馈／口碑／VOC”是分析意图，不会误当现象。`坐椅`会归一为`座椅`；`坐位`会作为“可能指座椅”的候选请你确认。主题带车型时按“车型”列过滤；未带车型且存在多个车型时，先让你选具体车型或全部车型。主关键词匹配二、三、四级标签与观点标签的合并字段，现象条件匹配观点标签。
2. **口径确认**——报告类型（周／月／专项）和主口径时间范围未说明时必须先确认；对象、车型、相关词等只要会实质改变结论也必须确认。可多轮确认，直到口径完整；没有歧义才按推荐方案执行。
3. **执行产出**——跑 9 个分析模块，出四件套。
4. **飞书推送**——仅在你明确要求时推给你自己。

主题词允许有错别字和同义说法（比如"发功机"、"异向"）。命中的扩展词会原样列出来给你确认，不会偷偷算进口径。

只给对象不给现象时（"座椅"、"轮胎"），不会瞎猜一个现象收窄口径，而是给出对象全覆盖结果**并报出正负面占比**，默认建议全貌读法（负面定位问题、正面看口碑资产、中性看咨询期望）——这类词往往大部分是好评，不报占比你无法判断。

## 不处理

| 场景 | 该用哪个 |

## 本地安装

将整个 `budui-voc-brief` 目录复制到 `~/.workbuddy/skills/`，然后重新打开会话。

本技能为个人本地分支，**未发布**，没有 `npx skills add` 地址；如需同步到其他机器，直接复制目录即可。

验证：

```bash
python "$HOME/.workbuddy/skills/budui-meta-skill/scripts/validate_skill.py" "$HOME/.workbuddy/skills/budui-voc-brief"
```

依赖：`openpyxl`、`Pillow`、`numpy`、`lark-cli`（飞书推送），以及 Chrome 或 Edge（渲染 PNG/PDF）。
脚本会通过 `common.add_site_packages()` 自动探测隔离环境的 site-packages，无需手工配置路径。

主题视觉维护：编辑 `scripts/build_theme_visuals.py` 中的对象几何或新增 `assets/svg/icon-*.svg`，重建 `assets/theme/hero-*.svg`，然后用 `assets/icon-sheet.html` 检查全套。生成的报告内联 SVG，无需在线图片服务。

## Troubleshooting

| 现象 | 原因 | 处理 |
|---|---|---|
| 没有自动触发 | 新会话尚未加载技能 | 重新打开会话，或直接说"分析 XX 问题" |
| 停下来问数据文件 | 你没给路径，技能不猜路径 | 贴上 CSV/Excel 的完整路径 |
| 卡在口径确认，不出报告 | 候选口径会实质改变结论，需要你的选择 | 回复 A/B，或补充你要看的业务边界 |
| 报 `ModuleNotFoundError: openpyxl` | 用了没装第三方包的解释器 | 换隔离 venv 的 python 运行脚本 |
| PNG/PDF 没生成 | 没找到 Chrome/Edge | 装 Chrome 或 Edge，脚本会自动探测 |
| 飞书没收到 | 没装 `lark-cli` 或未授权 | `npx skills add larksuite/cli -g -y`；推送失败不影响本地文件 |
| 月报趋势图只有 1～2 个点 | 数据跨度不足 6 个月 | 属正常，口径说明里会标注实际区间 |

## 规则来源

口径三层定义、互斥形态归并优先级、万分比渗透率算法、周期归一规则、洞察判据阈值与版式规范，均内化在本技能内
（`references/module-spec.md`、`references/ui-spec.md`）。技能只使用你提供的数据文件，不联网，不保存客户原始数据。
唯一的外部网络访问是飞书推送（`lark-cli`）。
