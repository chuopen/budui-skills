## 4. 关键组件规格

### 头部
- 品牌行：11.5px / 700 / 当前主色，左侧 16px 主色圆角小方块
- 大标题：29px / 800，第一行当前主色，第二行 `#2B2B2B`（`em` 换行）
- 周期标签：13px / 700，当前主色文字 + `1.6px solid` 当前主色边框 + 白底，`border-radius: 7px`
- **主题视觉**：画布 `320×250` SVG，CSS 展示宽约 `280px`，定位在头部右侧并允许向画布边缘越界。没有独立小色块、边框或卡片。统一的技术底纹、投影、偏移轮廓、主轮廓与细节层使视觉有浅半立体感；局部被左侧渐隐遮罩淡化。
- 头部至少 `240px` 高，主题视觉在文字下层；品牌行、标题和周期标签保留完整对比度。标题文案区域优先，长主题允许换行，视觉不能压字。头部下沿与总量卡保持原有间距，视觉只在头部内裁切，不得盖到数值。
- 色彩只用第 2 节选定预设；主题视觉主线比标题弱，细线、阴影和面填充以透明度控制。禁止照片、拟真高光、夸张透视和装饰性数据标注。

### 总量卡
- 渐变底 + `border-radius: 14px` + 光晕（`::after` 半透明白圆）
- 标题行 13.5px / 700 + 22px 半透明图标位
- 数值 38px / 800，单位 15px / 600
- 下方白色内嵌卡：**情感三分布**——三行（正面 `#079781`／中性 `#8C8C8C`／负面 `#E64340`），每行 `44px 标签 | 62px 数值+占比 | 三段堆叠条`，行间虚线分隔；堆叠条高 7px 圆角，三段宽度按各自占比、不足 6% 的段并入邻段显示（避免不可见窄条）
- 正面条数 < 10 时内嵌卡回退为「负面声音 / 负面率」两行聚焦版式（原 1.0 版式），不出现占比近零的三段条

### 条形图（负面风险主题 / 口碑亮点 / 外溢）
- 行网格：`79px 1fr 28px`，行距 7px
- 标签：10px / 右对齐 / `white-space: nowrap`（**必须 nowrap**，否则长标签折行）
- 条：高 14px，当前预设浅底，填充当前主色渐变；**口碑亮点的条填充绿色渐变 `#9CD6CB → #079781`**（语义色，不随预设切换）
- 数值：10.5px / 800 / 当前主色深色（口碑亮点行用 `#079781`）

### 口碑亮点区块（⑥b）
- 标题「口碑亮点」+ `assets/svg/mod-praise.svg`（14px，与其他区块标题图标同规格；拇指强调填充用语义绿 `#079781`，例外于「强调填充红」的 issue-* 规则——praise 是正面语义图标）
- 副标题一行小字：「正面 N 条 · 客户在夸什么」（9.5px / `#A8A8A8`）
- 内容：正面观点标签 top5 条形（绿色渐变，规格同条形图）+ 1 条好评代表性原声（规格同⑩原声卡，竖线用 `#079781`）
- **渲染条件**：主口径正面条数 ≥ 10（`pos_present_min`）；不足时整块不渲染，⑫ 口径说明加一行「正面 N 条（x%），未达亮点呈现阈值」

### 环形图（类型占比）
- SVG `viewBox 0 0 116 116`，`r=45`，`stroke-width=22`
- 环底色板顺序：`#F5820B → #FFB347 → #FFD8A8 → #E64340 → #8C7A66 → #D9D3CB`
- 中心显示总数 + 「条」
- 右侧图例：色块 9px + 名称 + 数值（`margin-left:auto`）

### 双轴趋势图
- SVG `viewBox 0 0 470 208`
- 左轴：周期均值 0–6；右轴：占全量比 0–80
- 柱：宽 30，`rx=3`，橙渐变；**峰值周期用红色渐变**（`#FF8A65 → #E64340`）
- **柱数值必须放柱内**（`y = 柱顶 + 15`，白色 10px 粗体）——放柱外会被折线点压住

- 轴标题用中文「日均」「万分比」

### m9 决策摘要卡（区块 ③）
- 底色 `#FFFBF4`，边框 `1px solid #F7E7CF`，`border-radius: 11px`
- 一句话结论：12.5px / 800 / `#C4620A`，行高 1.7
- 下方优先级计数行：三个等宽小格，网格 `1fr 1fr 1fr`
  - 每格：数字 20px / 800（P0 `#E64340`／P1 `#F5820B`／P2 `#8C8C8C`）+ 标签 9.5px / `#A8A8A8`
  - 无该优先级时数字显示 `0` 且整格降为 `opacity: .45`

### m9 洞察卡（区块 ⑧）
- 结构：**左侧色条 + 右侧内容**，网格 `3px 1fr`，`border-radius: 0 11px 11px 0`
- 底色 `#FFFBF4`，边框 `1px solid #F7E7CF`（左侧条用 `border-left-width: 0` 避免双线）
- **左色条按 level 取值**：`red` → `#E64340`｜`amber` → `#F5820B`｜`info` → `#C9C0B4`｜`good` → `#079781`

  + 洞察类型小字（9.5px / `#A8A8A8`）
- 结论正文：12px / 800 / `#2B2B2B`，行高 1.6
- 支撑事实：10.2px / `#7A7A7A`，行高 1.68，每条前加 `· `，最多 2 条
- 待验证方向：10.2px / `#5A5A5A`，前缀「待验证方向」用 `#C4620A` 700

## 5. 图标使用位置（全部内联 SVG）

| 位置 | 文件 | 尺寸 |
|---|---|---|
| 头部主题视觉 | `assets/theme/hero-*.svg` | 宽约 280px，320×250 viewBox |
| 类型占比区（形态） | `assets/svg/issue-*.svg` | 18px |
| 区块标题左侧 | `assets/svg/mod-*.svg` | 14px |

区块标题统一为：`4px × 15px` 当前主色竖条 + 标题文字（15px / 800）。

### 主题视觉体系

- `assets/svg/icon-*.svg` 保留作为 100×100 的旧版语义轮廓及小图标来源；新封面只用 `assets/theme/hero-*.svg`，两者不混用。
- 14 个现有具体主题、5 个大类和 generic 均有同名 `hero-*.svg`。匹配沿用 `assets/icon-map.json` 的对象词 → 小图标 → 大类 → generic 链；渲染时将经过校验的 `icon-*.svg` 映射到同名 hero 文件，缺件时安全降级到对应大类或 generic。
- 同一视觉骨架：浅色透视轨迹与节点（环境层）→ 柔和投影和偏移轮廓（深度层）→ 对象轮廓及少量结构细节（主层）。不同主题只替换对象几何；视觉重量、方向、透明度一致。发动机、门把手、车机、座椅、空调必须能在大尺寸看出对象特征。
- 可识别性先于几何风格：门把手必须带车门钣金线、把手凹槽与可握持凸起，不能画成一只圆角电子设备；车机应有屏幕与中控关系，座椅应有头枕／靠背／坐垫，发动机应有缸盖和管路，空调应有出风口与叶片。正常封面尺寸下不看标题也应能辨认对象。
- 新增主题先补 `assets/svg/icon-*.svg` 和 `assets/theme/hero-*.svg`，再登记 `assets/icon-map.json`，最后在 `assets/icon-sheet.html` 校验；不要把 100×100 小图放大顶替 hero。
- 自检：封面 480px 宽和导出 2× 像素时，标题／周期清晰、对象可识别、总量卡与下方图表不被覆盖；无主题时也不出现空白区。

## 6. 数值呈现规则

1. 渗透率、占比一律**万分比**，写「万分之 X」或「万分比」，**禁止用 ‱ 符号**（小字号渲染不可辨）
2. 大数字用 `10,046` 千分位
3. 每 10 条以上区间的结论必须带分母（如「占 142 条中的 36%」）
4. 样本量 < 30 时，图与结论旁加「样本量小，仅供参考」

## 7. 导出规格

| 产物 | 参数 |
|---|---|
| PNG | Chrome `--headless=new --screenshot --force-device-scale-factor=2 --window-size=504,<H>`，渲染后自动裁掉底部空白 |
| PDF | 需 `@media print{@page{size:504px <H>px;margin:0}}` + `--no-pdf-header-footer`，得到**单页长图** |

`<H>` 按内容高度估算（初始 4200 足够，渲染后裁剪）。
