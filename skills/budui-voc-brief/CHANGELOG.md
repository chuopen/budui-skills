# Changelog

版本号以 `manifest.json.version` 为唯一来源；`SKILL.md` 的 frontmatter 必须同步。

## 1.22.0 — 2026-09-22

- 海报集中度分布移至关键洞察之前，先呈现分布事实再给出推导结论。
- 公域舆情观察固定在海报最末内容区，替代数据体检与口径说明；未启用公域时明确标记，完整口径、体检和溯源仍保留在 Excel。

## 1.21.2 — 2026-09-22

- 修复对象词被误拆为观点现象条件的问题：对象词已包含该词时，自动取消重复的“且观点标签含……”过滤，避免口径文案重复和漏数。

## 1.21.1 — 2026-09-22

- 修复全貌海报三档情感卡片使用未定义 `pct` 变量的问题；改为函数参数 `pct_`，正面声量达到全貌阈值时不再渲染失败。

## 1.21.0 — 2026-09-22

- 将对外“问题形态规则引擎”统一更名为“观点主题归并”。
- 新增正面体验主题和中性咨询主题规则；三种情感独立统计覆盖率、未归并项和排行，禁止跨情感混算。
- 负面风险主题仍是唯一可触发风险结论的主题层；覆盖率不足时不展示负面主题图，并给出待补规则证据。

## 1.20.0 — 2026-09-22

- 飞书 CLI 查找改为显式路径、PATH、Windows 本地回退；dry-run 失败时可从配置读取唯一身份，多身份拒绝猜测。
- 形态规则覆盖不足时，保留不展示形态图的保护，同时披露未覆盖数量和待补规则高频观点。

## 1.19.0 — 2026-09-22

- 修复外溢关键词门槛丢失的 P0 问题：外溢服务、比值和洞察仅使用可回指关键词的直命中记录。
- 新增用户确认的关联扩展层，单列展示，不参与直命中外溢统计；明细新增外溢层级与命中词。

## 1.18.0 — 2026-09-22

- 主关键词匹配范围从二／三／四级标签扩展至二／三／四级标签＋观点标签合并字段；车型仍只来自车型列，现象条件仍只过滤观点标签。

## 1.17.0 — 2026-09-22

- 修复非琥珀主题总声量卡片残留橘色光晕：投影由主题令牌控制，蓝、绿、紫、曜石分别使用本主题阴影。

## 1.16.0 — 2026-09-22

- 增加口径基线冻结与影子审计：重复运行复用主口径，同时持续发现潜在漏项；候选达到阈值后才请求确认并创建新版本。

## 1.15.0 — 2026-09-22

- 修复“最近完整自然周”可错误选入未结束当周的 P0 口径问题：profile 输出数据截止日前的最后完整周，analyze 对不匹配时间窗直接拒绝执行。

## 1.14.0 — 2026-09-21

- 公域搜索不再把私域周/月日期作为硬查询条件；结果按同期、近期背景、历史背景或日期未知标记，避免周报因公网发布时间稀疏而空白。

## 1.13.0 — 2026-09-21

- 修复旧版 Python 不支持的嵌套 f-string，海报公域区可正常渲染。
- 公域证据写入后强制重跑 `analyze.py` 合入新的 stats，再渲染四件套，避免渲染旧空数据。

## 1.12.0 — 2026-09-21

- 公域层恢复为用户明确要求后启用，避免默认搜索拖慢私域简报。
- 修复公域证据文件按技能目录读取导致的丢失：现支持工作目录相对路径，并把缺文件/坏 JSON 如实呈现为载入失败而非“未检索到”。

## 1.11.0 — 2026-09-21

- 公域层增加 WebSearch 强制调用门槛、两轮检索回退与检索运行记录；工具失败必须如实标注，不能伪装成无公开证据。

## 1.10.0 — 2026-09-21

- 公域 Web 搜索改为每次简报默认并行执行；未检索到可核验结果时仍保留公域区并如实说明。
- 移除海报右上角封面图；标题下方改为真实的“报告类型／统计区间 · YYYY/MM/DD–YYYY/MM/DD”，不再把跨期数据误标成周报。

## 1.9.0 — 2026-09-21

- 新增与私域并行的公域链接证据层；海报下半部分以冷灰蓝底色独立呈现，公私域不混算。

## 1.8.0 — 2026-09-21

- 封面右上角不再按汽车部件匹配图片；部件专项使用通用 VOC 洞察图，车型全景使用整车图。

## 1.7.0 — 2026-09-21

- 新增车型全景模式：识别到车型但没有部件／对象词时，以车型列作为主口径，并用问题域排行替代跨部件问题形态。

## 1.6.0 — 2026-09-21

- 取消“只能询问一次”限制；所有会改变统计口径、结论或交付的未决项，必须通过一轮或多轮确认消除。
- 用户未说明时，报告类型（周／月／专项）和主口径时间范围成为必确认项；专项须选定范围。
- 修复非琥珀主题头部遮罩沿用暖橙 RGB 值的问题，改为中性白色遮罩，让主题底色完全由对应预设控制。
- `analysis_date_range` 已进入执行口径：主指标严格按确认日期窗计算，历史同主题记录只作趋势参照；周趋势改显示自然日期范围。

## 1.4.0 — 2026-09-21

- 增加意图与词汇归一阶段，先拆分车型、对象与现象再做口径发现。
- `声音`、`反馈`、`口碑`、`VOC` 不再误作现象条件。
- `坐椅`归一为`座椅`；`坐位`识别为相关词候选，必须确认后才能纳入口径。

## 1.5.0 — 2026-09-21

- 问题形态改为仅统计负面声音，正面/中性只按原始观点标签呈现。
- 未归并负面记录只保留内部追溯字段，不再以“其他”进入简报、排行、环图、洞察或摘要。
- 新增形态规则覆盖率门槛（85%）：未达门槛时不展示形态图，也不触发“问题高度同质”。
- 修复回归测试覆盖 `unittest.TestCase.run`、导致测试实际未运行的 P0 验证失效；新增“未归并不外显”回归用例。

## 1.3.0 — 2026-09-21

- 车型从“车型”列独立识别与精确过滤，不再混入标签或观点匹配。
- 多车型且用户未指定时，要求选择一个车型或全部车型。
- 对象关键词改为二、三、四级标签合并匹配；现象词仅匹配观点标签。

## 1.2.0 — 2026-09-21

- 阻止资源不完整时生成颜色、主题视觉失效的海报。
- 修复口径发现阶段的情感归一和纯现象词识别。
- 移除配置集中度；专营店仅使用名称字段。
- 原声按来源行与文本去重，海报内不重复展示同一条。
- 新增输入文件、口径和明细行的血缘信息及回归测试。
- 飞书推送改为用户明确要求后执行。

## 1.1.0 — 2026-09-20

- 正/中/负全貌呈现与 m9 判断层。
