# budui-voc-daily · VOC 新车日报生成器

导入人工校验后的 VOC 明细 Excel，说一句「出 9 月 12 号的日报」，即可得到一份日报 HTML 简报和一份带溯源 Sheet 的导出 Excel。统计口径由脚本固定执行，每次产出数字一致、可核对。

## 安装

- 上传到 WorkBuddy 等 Agent 平台：直接上传本技能目录（含 `SKILL.md` 与 `scripts/`）。
- 本地使用：把目录复制到 `~/.zcode/skills/`（或其他技能目录），或直接在目录内运行脚本。

依赖：Python 3.8+ 与 `openpyxl`（`pip install openpyxl`）。

## 使用

对装了本技能的 Agent 说：

- 「出 9 月 12 号的日报」（先要 Excel，再确认哪个车系是新车）
- 「出今天的新 N7 车系日报」
- 「N6 和 NX8 各出一份，车友群要点也放进去」

Agent 会自动识别工作表与字段 → 确认新车车系与日期 → 生成：

| 产物 | 内容 |
|---|---|
| `VOC新车日报_<车系>_<日期>.html` | 指标卡、情感结构、逐日趋势（堆叠柱＋负面占比折线）、观点 TOP5、热门话题 TOP3、逐日明细、数据来源与识别口径；自包含可离线打开 |
| `VOC新车日报_<车系>_<日期>.png` | 日报整页长图，直接发微信群用；脚本自动调用本机 Edge/Chrome 截取，无浏览器环境自动跳过 |
| `VOC新车日报_<车系>_<日期>.xlsx` | 总览、观点、热门话题、负面VOC清单、VOC明细 五个 Sheet，溯源首列为真实日期单元格，可直接排序筛选透视 |

## 数据要求

- 人工校验后的 VOC 明细 Excel，含：日期列（建单时间/数据日期/日期等）、情感列、标签类型列、观点标签列、四级标签列；有车系列与 OneID/VIN/服务单号时去重更完整。
- 字段名不完全一致没关系，脚本按候选名模糊识别；识别失败会明确列出缺失项，可手动指定列。
- 当前口径只分析单一指定车系（"新车"），不做车系间对比。

## 核心口径（摘要）

- 同一日期内三轮串行去重：①OneID＋观点＋四级标签；②VIN（规范化）＋观点＋四级标签；③服务单号＋观点＋四级标签；占位符无效，按日去重、不跨日合并。
- 总览指标为报告日期当日口径；趋势与热门话题为数据周期累计口径。
- 情感按"正/中/负"关键词归类，无法归类的单列为未识别，不并入三类。
- 完整口径见 `references/data-spec.md`，产出规范见 `references/report-spec.md`。

## 边界

不用于模型准确率监控、周报/月报聚合、多车系横向对比，以及没有人工校验标签的原始数据。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示缺少 openpyxl | 执行 `pip install openpyxl` 后重试 |
| 报「必需列识别失败」 | 按报错里的表头清单，用 `--col 日期=列名,情感=列名,...` 手动指定 |
| 报「车系 XXX 无记录」 | 车系名要与 inspect 输出的车系清单完全一致（区分大小写与全半角） |
| 报「无去重后数据」并列出可用日期 | 报告日期不在数据范围内，改用列出的日期 |
| 生成的日报车系不对 | 检查是否把其他车系当成了新车；inspect 的车系清单是唯一可选来源 |

## 背景与来源

为「新车日报」场景定制。参考实现为内部 web 版日报工具（新N7 VOC 日报，index.html + server.js），本技能将其统计口径固化为离线脚本并泛化车系：表选择从"行数最多"改为"结构特征匹配"（避免选中隐藏的模型校验窄表），车系从硬编码"新N7"改为自动识别＋人工确认"哪个车系算新车"。技能市场检索（2026-09-29，skills.sh）未见同类 VOC 日报技能，无直接借鉴对象。
