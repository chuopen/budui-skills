# 日报内容与产出规范（output contract）

## 产出文件

文件名前缀 `VOC新车日报_<车系>_<YYYY-MM-DD>`，三个产物：

| 文件 | 内容 |
|---|---|
| `.html` | 单文件自包含（内嵌 CSS 与 SVG，无外网、无 JS 依赖），浏览器打开即读 |
| `.png` | 整页高清长图（2 倍采样，2560px 宽），直接发群用；方法借鉴 budui-voc-brief：按布局估算高度截大视口 + `--force-device-scale-factor=2`，再像素级检测非背景行精确裁掉底部空白（需 Pillow+numpy，缺则跳过裁剪原样交付）；找不到浏览器时整体跳过并在 stdout JSON 中说明（`png: null` + `png_note`），不阻断日报交付 |
| `.xlsx` | 导出 Excel，五个 Sheet |

视口高度由布局模型按实际行数估算（固定区块校准常数 2702 ＋ 逐日行×34 ＋ 观点/话题缺行补偿 ＋ 车友群/警示加成，×1.35 余量）——估算只影响裁剪量，不影响正确性。截图文件在浏览器退出后延迟 1-2 秒落盘，脚本轮询等待；首次失败自动重建 profile 重试一次。

## 日报 HTML

单文件自包含（内嵌 CSS 与 SVG，无外网、无 JS 依赖），文件名 `VOC新车日报_<车系>_<YYYY-MM-DD>.html`。分区顺序固定：

1. 标题栏：日报标题 · 车系 · 报告日期 · 数据周期 · 车系筛选说明
2. 指标卡：VOC 总量、用户量、负面占比（当日口径）
3. 当日情感结构：正/中/负三行，数量＋占比＋进度条；有未识别记录时加警示行
4. 每日 VOC 趋势：SVG 堆叠柱（正/中/负）＋负面占比折线（橙色圆点＋百分比标注），横轴 MM/DD，图例齐备
5. 当日观点榜：产品侧、服务侧各一行三列（正/中/负 TOP5），观点量用浅色轨道未填满横条
6. 热门话题 TOP3：产品侧、服务侧各一表，四级标签＋累计声量＋逐日迷你趋势（峰值红点）＋峰/谷日期与数值
7. 逐日明细表（日期、正、中、负、未识别、合计、用户量），供核对
8. 车友群动态（仅当传入 `--group-extra`）
9. 数据来源与识别口径：文件名、工作表、日期列、车系筛选、参与统计行数链路（命中 → 周期去重 → 当日）、去重口径全文；可折叠查看识别字段映射
10. 页脚：生成工具与生成日期

视觉：暖白底、白卡片、橙色主色（#e8730c）、情感色固定（正面绿 #2e9e5b / 中性灰 #8a94a6 / 负面红 #d64545）；所有用户数据经 HTML 转义。

## 导出 Excel

文件名 `VOC新车日报_<车系>_<YYYY-MM-DD>.xlsx`，五个 Sheet：

| Sheet | 内容 |
|---|---|
| 总览 | 信息块（文件名、工作表、报告日期、车系筛选、日期列、车系命中行数、周期/当日去重数、用户量、观点量、未识别、负面占比小数、去重口径、识别字段映射）＋ 逐日表（含用户量列） |
| 观点 | 侧别 × 情感 × 排名 × 观点标签 × 数量 |
| 热门话题 | 侧别 × 排名 × 四级标签 × 累计声量 × 峰值日期/值 × 谷值日期/值 |
| 负面VOC清单 | 报告日期 ＋ 该车系 ＋ 去重后情感为负面的记录，首列为日期列（真实日期单元格，格式 `yyyy-mm-dd hh:mm:ss`），其余列沿用源文件表头 |
| VOC明细 | 同筛选全部记录，首列日期前置，其余沿用源文件列 |

负面占比以小数输出（0.3898），Excel 中套百分比格式即显示 38.98%。

## stdout 摘要 JSON（给汇报用）

`ok / html / png / png_note / excel / stats{date, series, total, users, sentiment{正面,中性,负面}, unrecognized, negative_ratio}`；PNG 成功时 `png` 为路径，失败为 `null` 并附中文 `png_note`。

## 验证清单（每次改动脚本后必跑）

1. inspect 对真实文件能识别全部 9 个字段、车系清单、日期范围
2. generate 后：`stats.total` ＝ VOC明细数据行数；`sentiment.负面` ＝ 负面VOC清单行数；负面占比 ＝ 负面 ÷ 当日总量
3. HTML 打开无乱码、图表渲染、口径数字与 stdout 一致
4. Excel 五个 Sheet 齐全，溯源 Sheet 首列日期可直接排序筛选
5. PNG 生成成功且页脚完整可见、底部空白小于 300px（视口高度估算的回归检查）
