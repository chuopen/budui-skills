# VOC 新车日报

把一份人工校验后的 VOC 明细 Excel 变成一份当日新车日报（HTML 简报 + 导出 Excel）。统计口径全部由 `scripts/generate_report.py` 固定执行，不要手写统计代码或口头估算数字。

## 何时使用 / 不使用

使用：用户导入 VOC 明细 Excel 并要求生成某天的日报（"出 9 月 12 号的日报""要今天的新车日报"）。
不使用：模型准确率监控、周报/月报聚合、车系横向对比分析、没有人工校验标签的原始数据——这些直接答复或另建技能。

## 工作流

### 1. 环境检查

```bash
python -c "import openpyxl" 2>/dev/null || pip install openpyxl
```

### 2. 探测结构（必做）

```bash
python scripts/generate_report.py inspect <excel路径>
```

读取 JSON 输出：选中的工作表、9 个字段映射、**车系清单及条数**、日期范围、缺失字段。
- `missing_required` 非空 → 把缺失字段和表头清单告诉用户，让用户指定列名，用 `--col 日期=列名,情感=列名,...` 重试。
- 用户点名了某个工作表 → 加 `--sheet`。

### 3. 确认新车车系（必做，不可跳过）

车系是**自动识别**的，但"哪个车系算新车"必须由用户决定——这是新车日报与普通 VOC 日报的唯一区别。向用户展示 inspect 的车系清单（如 NX8 1572 条、N7 1280 条、N6 871 条、天籁 496 条…），问一句："哪个车系是本期的新车？"

- 用户已在对话里说明（"出 N7 的日报"）→ 不再重复问。
- 用户要多个车系 → 每个车系各执行一次 generate，产出多份日报。

### 4. 确认报告日期

用户说了日期就用它（支持"今天""9月12号"等，换算成 `YYYY-MM-DD`）。没说才问。
日期不在数据范围内时，脚本会报错并列出可用日期——把可用日期告诉用户，不要自行替换日期。

### 5. 生成日报

```bash
python scripts/generate_report.py generate <excel路径> --date 2026-09-12 --series N7 \
  [--outdir 输出目录] [--title "VOC 新车日报"] [--group-extra "车友群要点1|要点2"]
```

- `--group-extra`：用户提供了车友群截图/文本时，提取要点后用 `|` 分隔传入；没有就省略。
- 输出目录：用户没指定时用 `--outdir <excel同目录>/日报输出`。
- 默认同时输出 PNG 高清长图（脚本调用本机 Edge/Chrome 2 倍采样截图并自动裁掉底部空白，方法同 budui-voc-brief）；环境无浏览器时 JSON 里 `png` 为 `null` 并附 `png_note`，如实说明即可，不要尝试用其他方式截图。

### 6. 汇报（必须做）

生成成功后，读 stdout JSON，用中文向用户汇报并给出文件路径：

1. 一句话结论：当日 VOC 总量、负面占比、用户量
2. 负面 TOP 话题（产品侧/服务侧第一条热门话题）
3. 三个产物文件路径（HTML 日报 + PNG 长图 + 导出 Excel）；PNG 用于直接发群
4. 数据口径提示：统计的车系、报告日期、去重口径已写入日报"数据来源与识别口径"节

## 边界与注意

- 数字一律以脚本 stdout JSON 为准；不要凭记忆复述或心算改数。
- 车系值必须原样取自 inspect 的 `series_values`（如 `N7`，不是"新N7"），脚本按字符串精确匹配。
- 报告聚焦所选日期当天：总览/观点榜是当日口径，趋势图与热门话题是数据周期累计口径，两者都写在日报里。
- 导出 Excel 的百分比以小数输出（0.3898），在 Excel 中套用百分比格式即显示 38.98%。
- 日报 HTML 自包含（内嵌 SVG，无外网依赖），可直接发群或浏览器打开。
- 更细的字段识别规则与去重口径见 [references/data-spec.md]；日报内容结构见 [references/report-spec.md]。
