# budui-伙食补贴发票报销 · 节假日伙食补贴报销表生成

把一个按日期分文件夹的节假日伙食补贴电子发票 PDF 目录 + 工资号字典 Excel，变成三份交付物：按日期分 Sheet 的报销明细 Excel、按人统计的伙食补贴汇总表、一份 Markdown 问题报告。提取、查重、校验、统计全部由脚本固定执行，每次产出数字一致、可核对。

## 安装

```bash
npx skills add chuopen/budui-skills --skill budui-伙食补贴发票报销
```

或把本目录复制到 `~/.zcode/skills/`（或其他技能目录）。依赖：Python 3.8+、`pymupdf`、`openpyxl`。

## 使用

对装了本技能的 Agent 说「处理 XX 节假日伙食补贴发票，出明细表、汇总表和问题报告」，或直接运行：

```bash
python3 scripts/build_detail_workbook.py \
  --invoice-dir "<发票根目录>" --dict-xlsx "<工资号字典.xlsx>" \
  --atten-note "2026.10.1=10月1-2日" \
  --out "<明细.xlsx>" --report "<报告.md>" \
  --summary-out "<每人汇总表.xlsx>" --summary-title "2026年春节专项伙食补贴汇总表（七大组）" \
  --summary-sheet "餐补汇总表（无餐车）" --summary-note "2月17-22日"
```

| 产物 | 内容 |
|---|---|
| 明细 Excel | 每个开票日期一个 Sheet（发票号/开票日期/金额/使用人/所属节日，序号补足 20 行、合计行、考勤说明、签名行）+「合计」Sheet |
| 每人汇总表 | 独立 xlsx：部门/工资号/职名/当班天数/金额（天数=有效票日期去重数，金额=天数×50），内嵌工资号字典供 VLOOKUP，A4 单页竖排 |
| 问题报告 | 待确认票、抬头异常票、无法解析 PDF、查重结果、同人同天冲突、汇总表对账等，交付前必须逐条人工确认 |

## 核心规则（摘要）

- 每人每天最多 50 元，使用人人数上不封顶：实报 = min(人数×50, 发票金额)；余额 ≥50 时标红「可加X人」
- 按发票号查重（同号取文件名人名多的那张）；购买方名称+税号不匹配的票不入表、单独提示退回重开
- 文件名人名按规则解析（连写人名按字典拆分），字典外姓名照常输出并加批注
- 汇总表总计与明细实报自动对账，差额按「可加X人/发票封顶/同人同天重复」分解

完整规则见 `SKILL.md`，逐格版式见 `references/format-spec.md`，回归用例见 `evals/test_regressions_202610.py`（改解析或统计逻辑后必须跑）。

## 边界

不用于：没有发票 PDF、只凭考勤数据做工资号表；发票重开流程；非铁路报销场景。

## 背景与来源

广九客运段节假日（中秋、国庆、春节等）伙食补贴报销的实际交付工作流沉淀，版式对齐真实交付件。作者：不兑 (budui) · https://github.com/chuopen/
