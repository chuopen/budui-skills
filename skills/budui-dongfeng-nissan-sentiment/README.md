# budui-dongfeng-nissan-sentiment

东风日产公域舆情监控与结构化数据采集技能。

## 用途

通过 WebSearch 搜索主流平台（汽车之家、懂车帝、小红书、微博、抖音、百度贴吧、知乎等）上指定车型的公开讨论，提取用户声音并输出带情感标签（正/中/负）的结构化 JSON 数据，供下游报告生成技能消费。

## 使用方式

手动触发，示例提示词：

- "帮我查一下天籁最近的舆情"
- "收集轩逸和逍客在各大平台的用户评价"
- "看看探陆车主对油耗和智驾的真实反馈"

## 输出

JSON 文件，包含 metadata（采集元信息、情感分布、平台覆盖）和 items（每条声音的结构化记录）。详见 `references/output-schema.md`。

## 限制

- 基于搜索引擎公开结果，不保证穷尽
- 情感标签由大模型判定，非人工标注
- 不涉及私域数据、账号登录或私有 API
